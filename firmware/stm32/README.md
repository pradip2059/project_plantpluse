# STM32 integration example

`plantpulse.c` is an STM32 HAL integration example, not a complete CubeIDE project. Add the files to your generated project, ensure `huart1` is configured, and call `PlantPulse_SendTelemetry(...)` with real measurements.

The repository intentionally does not claim this example has been validated on physical hardware yet. Once tested, record board model, CubeMX configuration, wiring, and test evidence here.
